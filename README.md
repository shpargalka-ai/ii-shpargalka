# ИИ-Шпаргалка

**Сайт:** https://shpargalka-ai.github.io/ii-shpargalka/

**План квеста за 5 минут.** Сайт помогает учителю 5–11 классов составить хороший запрос (промпт) для нейросети — GigaChat, Алисы AI или DeepSeek, — чтобы та подготовила план игрового урока или квеста.

Сайт **не** обращается к нейросетям сам и **ничего никуда не отправляет**. Он собирает текст запроса, учитель копирует его одной кнопкой и вставляет в чат нейросети.

Что есть на сайте:

- **Конструктор промпта** — учитель выбирает предмет, класс, тему, жанр игры, а промпт собирается сам. Места, которые лучше дописать, подсвечены жёлтым.
- **База из 18 готовых промптов** с фильтрами, поиском, подсказками «что дописать» и примерами «было → стало».
- **«Доработать ответ ИИ»** — короткие просьбы вроде «Сократи до 25 минут» или «Упрости под 5–6 класс».
- **Как это работает** — 4 шага, словарь терминов и чек-лист проверки плана от ИИ.
- **Безопасность**, **нормативные документы** (только ссылки), **О проекте** — для защиты работы.
- **«Мои промпты» и избранное** — хранятся только в браузере учителя.
- Работает **без интернета** после первого открытия, **печатает** карточку промпта, показывает **QR-код**.

## 1. Как открыть сайт у себя на компьютере

1. Скачайте папку проекта целиком.
2. Откройте её и **дважды щёлкните по файлу `index.html`**. Сайт откроется в браузере.

Больше ничего устанавливать не нужно. Интернет тоже не нужен.

> При открытии двойным щелчком не работают только две вещи: офлайн-режим (он и не нужен — файлы и так на компьютере) и QR-код на сам сайт на главной странице (у файла на компьютере нет адреса в интернете). После публикации (раздел 5) работает всё.

Если хочется проверить сайт «как в интернете» (например, офлайн-режим), можно запустить простой локальный сервер. Откройте Терминал в папке проекта и выполните:

```bash
python3 -m http.server 8000
```

Если Python не установлен (на Mac команда `python3` может предложить установить «инструменты разработчика» — это окно можно закрыть), используйте встроенный в macOS Ruby:

```bash
ruby -run -e httpd . -p 8000
```

Затем откройте в браузере адрес `http://localhost:8000`. Остановить сервер — сочетание клавиш `Ctrl+C` в Терминале.

## 2. Как добавить новый промпт

Все промпты лежат в файле **`js/data.js`**. Его можно открыть любым текстовым редактором: Блокнот (Windows), TextEdit (Mac — в режиме «Простой текст»), а удобнее всего — бесплатный редактор вроде VS Code или Notepad++.

**Шаг 1.** Откройте `js/data.js` и найдите строку `window.PROMPTS = [`.

**Шаг 2.** Сразу после неё вставьте новый блок. Удобнее всего скопировать любой существующий промпт и поменять в нём текст. Вот пример:

```js
  {
    id: 'moy-novyi-prompt',
    title: 'Ролевая игра «Экспедиция»',
    summary: 'Когда хочется закрепить тему через путешествие по карте.',
    subjects: ['География', 'Биология'],
    grades: [5, 6, 7],
    stage: 'Закрепление',
    genre: 'Ролевая игра',
    duration: 40,
    template:
`Ты — учитель, предмет — {{предмет}}.

Контекст:
— Тема: {{тема}}
— Класс: {{класс}}, количество учеников: {{количество}}
— Время: {{время}} минут
— Цель урока: {{цель}}

Задача: разработай ролевую игру «Экспедиция»…

Ограничения: …

Формат ответа: …

Критерии качества: …

Не используй персональные данные учеников.`,
    fields: ['предмет', 'тема', 'класс', 'количество', 'время', 'цель'],
    tips: [
      'Первая подсказка: что лучше дописать учителю.',
      'Вторая подсказка.'
    ],
    example: {
      before: 'Как обычно спрашивают (короткий слабый запрос).',
      after: 'Начало хорошего запроса с заполненными полями…',
      result: 'Коротко: что получается во втором случае.'
    }
  },
```

**Шаг 3.** Сохраните файл и обновите страницу в браузере. Новый промпт появится в базе и в списке шаблонов конструктора.

Что важно:

| Поле | Что писать |
|---|---|
| `id` | Уникальное имя латиницей, без пробелов, через дефис. Не должно повторяться. |
| `title`, `summary` | Название и одна строка «для чего». |
| `subjects` | Список предметов. Если подходит любой — `['Любой']`. |
| `grades` | Классы цифрами, например `[5, 6, 7]`. |
| `stage` | Одно из: `'Начало урока'`, `'Объяснение'`, `'Закрепление'`, `'Рефлексия'`, `'Контроль'` (или `'Доработка ответа'` для промптов-правок). |
| `genre` | Жанр, например `'Детектив'`, `'Квиз-баттл'`. Новый жанр сам появится в фильтре. |
| `duration` | Минуты цифрой (`40`) или `null`, если время не важно. |
| `template` | Текст промпта между обратными кавычками `` ` ``. Места для подстановки — в двойных фигурных скобках. |
| `fields` | Какие `{{…}}` использованы в тексте. |
| `tips` | 2–4 подсказки «что дописать». |
| `example` | Пример «было → стало» и что получилось. |

Места для подстановки, которые понимает конструктор: `{{предмет}}`, `{{класс}}`, `{{тема}}`, `{{количество}}`, `{{время}}`, `{{этап}}`, `{{жанр}}`, `{{цель}}`, `{{особенности}}`, `{{ограничения}}`, `{{формат}}`.

**Частые ошибки:** забыли запятую после закрывающей `}` блока; внутри `template` встретилась обратная кавычка `` ` ``; в других полях встретился апостроф `'` (замените на «ёлочки»). Если после правки сайт перестал показывать промпты — проверьте именно это.

## 3. Как поменять ссылки на нейросети

Ссылки на нейросети записаны **в одном месте** — в начале файла `js/data.js`:

```js
window.LINKS = {
  ai: [
    { id: 'gigachat', name: 'GigaChat', url: 'https://giga.chat', note: 'Сбер, нужен Сбер ID' },
    { id: 'alice', name: 'Алиса AI', url: 'https://alice.yandex.ru', note: 'Яндекс' },
    { id: 'deepseek', name: 'DeepSeek', url: 'https://chat.deepseek.com', note: 'Бесплатно, без регистрации по телефону' }
  ],
```

Поменяйте `url` (адрес) или `name` (название на кнопке) — и кнопки «Открыть…» и QR-коды на всём сайте обновятся сами. Можно добавить четвёртую нейросеть, скопировав строку.

> ⚠️ **Проверьте ссылки перед сдачей.** Адреса сервисов иногда меняются.

Там же, в `window.LINKS`, настраиваются:

- `feedback` — ссылка на Яндекс Форму для обратной связи (кнопка в подвале);
- `site` — адрес опубликованного сайта (нужен для QR-кода, если сайт открыт с компьютера);
- `docs` — список нормативных документов (название, зачем нужен, ссылка).

## 4. Как опубликовать сайт на GitHub Pages

GitHub Pages — бесплатный хостинг. Сайт получит адрес вида `https://ваш-логин.github.io/ii-shpargalka/`.

**Шаг 1. Зарегистрируйтесь.** Откройте github.com, нажмите зелёную кнопку **Sign up** в правом верхнем углу, введите почту, пароль и имя пользователя (логин). Логин станет частью адреса сайта.

**Шаг 2. Создайте репозиторий** (это «папка» проекта на GitHub). После входа нажмите **«+»** в правом верхнем углу → **New repository**. В поле **Repository name** напишите `ii-shpargalka` (латиницей). Ниже выберите **Public**. Нажмите зелёную кнопку **Create repository** внизу.

**Шаг 3. Загрузите файлы.** На открывшейся странице найдите ссылку **uploading an existing file** (в строке «…or upload an existing file»). Откроется область с надписью «Drag files here». Откройте папку проекта на компьютере, выделите **всё её содержимое** (файлы `index.html`, `constructor.html`… и папки `css`, `js`, `assets`, `vendor`) и перетащите в эту область. Важно: перетаскивайте содержимое папки, а не саму папку — `index.html` должен оказаться в корне. Дождитесь, пока загрузятся все файлы, и нажмите зелёную кнопку **Commit changes** внизу.

**Шаг 4. Включите Pages.** Вверху страницы репозитория откройте вкладку **Settings** (с шестерёнкой). В меню слева выберите **Pages**. В блоке **Build and deployment** → **Source** выберите **Deploy from a branch**. Ниже, в **Branch**, выберите `main` и папку `/ (root)`, нажмите **Save**.

**Шаг 5. Подождите 1–3 минуты** и обновите страницу Settings → Pages. Вверху появится надпись **«Your site is live at …»** с адресом сайта. Откройте его и проверьте.

**Шаг 6. Впишите адрес сайта** в `js/data.js` в поле `site` (например, `site: 'https://ваш-логин.github.io/ii-shpargalka/'`) и загрузите обновлённый файл (см. ниже). Тогда QR-код на главной будет работать, даже если сайт открыт с компьютера.

**Как обновить сайт после правок.** Откройте репозиторий, перейдите в нужную папку (например, `js`), нажмите **Add file** → **Upload files**, перетащите исправленный файл и нажмите **Commit changes**. Через минуту изменения появятся на сайте.

> Сайт работает офлайн, поэтому после обновления посетители сначала могут увидеть старую версию, а новая подтянется при следующем открытии. Если вы **добавили новый файл**, впишите его в список `FILES` в файле `sw.js` и поменяйте строку `var VERSION = 'v1';` на `'v2'` (потом `'v3'` и так далее).

## 5. Что проверить перед сдачей

- [ ] **Ссылки на нейросети** (`js/data.js` → `LINKS.ai`) открываются.
- [ ] **Форма обратной связи:** создайте Яндекс Форму и вставьте ссылку в `LINKS.feedback` вместо `'TODO: вставить ссылку на форму'`. Пока там TODO, кнопка «Обратная связь» показывает сообщение «скоро появится».
- [ ] **Адрес сайта** вписан в `LINKS.site` (после публикации).
- [ ] **Нормативные документы** (`LINKS.docs`): ссылки открываются и ведут на нужные документы. Ссылки были проверены 2 ноября 2026 года.
- [ ] **Таблица апробации** на странице «О проекте» (`about.html`) заполнена: найдите комментарии `<!-- заполнить после тестирования -->` и впишите данные в пустые ячейки. Без ФИО — только «учитель истории, 12 лет стажа».
- [ ] **Примеры «было → стало»** в промптах — иллюстрации. Хорошо бы прогнать несколько промптов через настоящую нейросеть и при необходимости поправить описание результата.
- [ ] **QR-код** сканируется телефоном (наведите камеру на код на главной или в конструкторе).
- [ ] Сайт открывается **с телефона** и **без интернета** (после первого открытия).

## 6. Из чего состоит сайт

```
index.html              Главная: «План квеста за 5 минут», 4 шага, «до / после», QR на сайт
constructor.html        Конструктор промпта — главный экран
prompts.html            База промптов с фильтрами и поиском
how.html                Как это работает, словарь, чек-лист проверки
docs.html               Нормативные документы (только ссылки)
safety.html             Безопасность и персональные данные
about.html              О проекте: актуальность, цель, задачи, апробация
my.html                 «Мои промпты» и избранное
css/style.css           Оформление, светлая и тёмная темы (цвета — в начале файла)
css/print.css           Как сайт выглядит при печати
js/data.js              ВСЕ ДАННЫЕ: промпты, ссылки, списки предметов, жанров и т. д.
js/app.js               Общее для всех страниц: тема, меню, копирование, уведомления, QR-окно
js/constructor.js       Логика конструктора
js/prompts.js           Карточки, фильтры и поиск в базе промптов
js/my.js                Страница «Мои промпты»
js/qr.js                Генератор QR-кодов (свой, без внешних библиотек)
assets/                 Значок сайта, иконки для телефона, картинка для соцсетей
vendor/                 Место для сторонних библиотек (сейчас пусто — они не нужны)
manifest.webmanifest    Описание сайта как приложения (значок, название)
sw.js                   Офлайн-режим: сохраняет файлы сайта в браузере
.nojekyll               Служебный файл для GitHub Pages (на Mac он скрыт; если не загрузился — не страшно)
```

Чаще всего вам понадобится только **`js/data.js`**: там промпты, ссылки, списки предметов и жанров, тексты кнопок «Доработать ответ ИИ».

Если захочется поменять цвета — они записаны в начале `css/style.css` (блок `:root` для светлой темы и два одинаковых блока ниже — для тёмной).

## Технические заметки

- Чистые HTML, CSS и JavaScript: без фреймворков, сборщиков и npm. Шрифты системные, иконки — свои, встроенные в код.
- Никаких внешних подключений, аналитики и cookie. Единственное хранилище — `localStorage` браузера (черновик конструктора, «Мои промпты», избранное, отметки чек-листа, выбор темы). Всё это можно стереть кнопкой на странице «Безопасность».
- Данные лежат в `js/data.js` как обычный скрипт, а не JSON — поэтому сайт работает при открытии файла двойным щелчком.
