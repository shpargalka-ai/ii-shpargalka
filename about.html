О проекте

«ИИ-Шпаргалка» — сайт-навигатор, который помогает учителю за 5 минут составить хороший запрос к нейросети и получить план игрового урока.

Актуальность

Игровые формы — квесты, ролевые игры, детективы — повышают вовлечённость учеников, но их подготовка занимает часы. Нейросети могут сократить это время, однако многие учителя их опасаются или получают бесполезные ответы, потому что не знают, как правильно сформулировать запрос.

Учителю нужен не ещё один курс по ИИ, а простой инструмент «здесь и сейчас»: с телефона, за перемену, без регистрации.

Цель

Снизить барьер входа в работу с нейросетями и сократить подготовку игрового урока на 2–3 часа за счёт готовых, правильно построенных промптов.

Целевая аудитория

Учителя-предметники 5–11 классов, которые хотят разнообразить уроки, но не умеют или боятся работать с нейросетями. Часто работают с телефона, в спешке и без стабильного интернета.

Задачи

  1. Изучить, какие трудности возникают у учителей при работе с нейросетями.
  2. Разработать единую схему промпта: роль → контекст → задача → ограничения → формат ответа → критерии качества.
  3. Создать конструктор, который собирает промпт из ответов учителя и подсказывает, что дописать.
  4. Подготовить базу из 18+ промптов для разных этапов урока и игровых жанров.
  5. Объяснить правила безопасной работы с ИИ и персональными данными.
  6. Провести апробацию с учителями и оценить экономию времени.

Что сделано

Конструктор промпта

Живое превью, подсветка незаполненных мест, кнопки «скопировать» и «открыть нейросеть».

База промптов

18+ промптов с подсказками «что дописать» и примерами «было → стало», фильтры и поиск.

Доработка ответа

Готовые короткие просьбы: упростить, сократить, добавить уровни сложности.

Безопасность

Понятные правила работы с персональными данными и чек-лист проверки ответа ИИ.

Работа без интернета

После первого визита сайт открывается офлайн. Можно скачать папку и открыть с компьютера.

Приватность

Никакой аналитики и серверов: сохранённое хранится только в браузере учителя.

Планы развития

  • Расширить базу промптов по итогам апробации: больше предметов и жанров.
  • Добавить промпты для внеурочной деятельности и классных часов.
  • Собрать примеры реальных уроков, проведённых по планам от ИИ (без персональных данных).
  • Провести семинар для методического объединения с QR-кодом на сайт.
  • Добавить раздел для промптов, которыми делятся сами учителя.

Как сделан сайт

Обычные HTML, CSS и JavaScript, без серверов, баз данных и внешних библиотек. Сайт можно открыть двойным кликом из папки, опубликовать на GitHub Pages и пользоваться без интернета.

ИИ-Шпаргалка — помощник учителю: промпты для нейросетей, чтобы быстрее готовить игровые уроки.

Сайт не собирает данные: всё, что вы сохраните, хранится только в вашем браузере.
